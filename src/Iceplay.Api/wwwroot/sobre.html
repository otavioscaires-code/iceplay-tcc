02 / Base técnica

Uma estrutura simples.
Um caminho para evoluir.

A primeira etapa reúne a interface, a API e a persistência de dados na mesma aplicação.

01

Interface web

Uma página responsiva para acompanhar as últimas leituras, gerenciar geladeiras e consultar o estado da aplicação.

HTML · CSS · JavaScript
02

API da aplicação

Recebe leituras do simulador e atende às consultas de cadastro. A integração física com o ESP32 será uma etapa futura.

ASP.NET Core
03

Persistência local

Um banco em arquivo para armazenar os dados. A verificação de saúde consulta o banco.

Entity Framework Core · SQLite
